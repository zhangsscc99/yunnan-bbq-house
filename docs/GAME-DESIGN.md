# 柳真真云南烤肉 — 游戏设计 (M1 垂直切片)

胡闹厨房 × 云南烧烤摊的单人模拟经营。玩家 = 摊主柳真真，出餐闭环只有
**上炉 → 起锅上菜** 两次点击（简化版见 §0/§1）。

## 0. 玩法方向（2026-11-22 用户定调，最高优先，覆盖其余条款）

> **画面模仿《胡闹厨房》，玩法不模仿。**
> 只要一件事：**一次点击完成一件事**，不要再把出餐拆成取料→切配→装盘→上菜这么多步。

- 移动端是唯一目标平台：**竖屏单手可玩**，全程不需要走位、不需要拖拽、不需要多指。
- **一条订单卡 = 一次点击**。玩家做的每一个决策都必须是"什么时候点这张卡"，不是"走几步、按几下"。
- 禁止新增任何多步骤工位（切配、装盘台、料箱走动一律删除，见 §1）。
- 复杂性只能来自**时机**与**优先级**（哪个顾客先、哪串该起了），不能来自**流程步骤**。

## 1. 核心循环（简化版，唯一有效版本）

```
顾客坐下 → 头顶出现订单卡（1 道菜 + 耐心条 + 一个圆形主按钮）
点一次卡  = 生串自动上炉（该卡进入"烤制中"，显示 6s 环形进度）
再点一次卡 = 起串上菜收款（成功 = 菜价 + 小费；点早了 = 夹生退款；点晚了 = 焦糊扣钱）
烤位只有 3 个 → 第 4 位顾客必须等，这就是玩家的排队决策
顾客耐心归零 → 愤怒离店（满意度 -1）
3 分钟倒计时 → 结算（星级 1–3）
```

- 玩家角色只是视觉表现，**不再需要跑图取料**；料箱/切配/装盘/垃圾桶全部从玩法里移除（美术资产可保留作布景）。
- 每张卡的整个生命周期只需要 2 次点击：**放下** 和 **起锅**。
- 判定窗口（建议）：生串 0–4s 点 = 夹生（退款，不扣钱）；4–9s 点 = 完美（满小费）；9–12s 点 = 偏老（小费 50%）；>12s 自动焦糊（扣钱 + 废料）。

已废弃条款（保留记录，别再实现）：切配台 3 次点按、装盘台、料箱按菜取串、手持物品走动。

## 2. 菜单与数值 (Lv.1)

| 菜品 | 料箱 | 售价 | 顾客耐心 | 说明 |
|---|---|---|---|---|
| 烤五花肉拼盘 | 五花肉箱 | ¥48 | 75s | 粉白五花纹理串 |
| 烤菌子 | 菌子筐 | ¥32 | 90s | 褐色菌菇串 |
| 豆泥米线 | 米线筐 | ¥26 | 100s | 黄色米线(装盘成碗) |

- 烤制：生串上炉 → 6.0s 熟 (窗口) → 12.0s 焦。熟后每多 2s 小费系数 -10%? 否——
  焦=废料。熟度区间 [6s, 12s) 均可取下，>12s 自动变废料冒烟。
- 切配：需 3 次点按，每次 0.22s 动画 + 进度条推进 1/3。
- 小费：上菜时 `tip = round(菜价 × 0.3 × 剩余耐心比例)`，耐心比例 ≥0.8 给满小费。
- 收款 = 菜价 + 小费，营业额累计。
- 顾客离开(满意/愤怒)后，桌子 4s 后可再坐。

## 4. 评分

```
星级 = f(营业额达成率 r = 营业额/目标, 服务顾客数 s, 愤怒离店数 a, 废料数 w)
  3★: r ≥ 1.0 且 a = 0 且 w ≤ 1
  2★: r ≥ 1.0 或 (r ≥ 0.7 且 a ≤ 1)
  1★: 其余(含 r < 0.5 → 也保底 1★ 鼓励)
  上限条款：served = 0（未服务任何顾客）时星级上限锁 1★；angry ≥ 3（愤怒离店 ≥ 3 位）时星级上限锁 1★。
  局内顶栏评级与结算面板共用同一计算函数，保证同局两处星级一致。
结算面板展示：星级 / 营业额(+目标) / 服务顾客数 / 满意度 / 废料数
```

## 5. 场地 (12m × 9m，1m 网格)

```
z=0   ┌ 后门墙：门(x=0..1)、辣椒串、菜单黑板 ┐
z=1-2   餐区：4 张方桌 (2.2,1.6)(5.8,1.6)(9.4,1.6)(7.6,3.6)
z=3-5   动线(空)
z=6     餐区-厨房过渡
z=7     厨房台面排(贴后墙 z=8):
        x=0 垃圾桶 | x=1..3 料箱×3 | x=4,5 切配台 | x=6..8 炭火烤炉(3位)
        | x=9,10 装盘台 | x=11 备用台
x=0,z=4..6  左墙 L 形：干菌子筐/陶罐装饰台
```

- 台面 = 1m 模块单元，玩家不可穿越；桌前顾客椅子不挡路。
- 玩家出生点 = 格 (3, 4)(世界 (-2.5, 0)，面朝 +z 即料箱排)：walkable、不在任何台面/桌面格内；
  到全部 11 个站点/桌 usePos 的最小欧氏距离 1.442m (t1 桌) > 1.20m (= §6 判定半径 1.15 + 0.05 余量)；
  按 §6 实际判定(站点包围盒距离，烤炉再 −0.35)距任一站点 ≥ 2.5m，开局不命中任何站点。
  旧值 (6, 5.5)/(6, 5.2) 距烤炉有效距离 ≤ 1.15m，开局即落在烤炉判定圈内，已废弃。
- 开局/离开站点圈时右下按钮不置灰：显示引导语(如「去料箱取料」)、opacity 1，点击弹 2s HUD 引导提示(不消耗输入)。
  **已废弃（第 32 轮，commit 61f17e1）**：动作键与站点走动整套 UI 已从局内删除，订单卡是唯一主操作入口。

## 6. 交互 (移动端优先)

- **唯一交互（第 32 轮定稿）**：点订单卡 `.card-btn` 两次——上炉、起锅上菜；不需要走位、不需要摇杆。
- 摇杆与右下动作键（旧条款）已随 `B-143` 删除，代码只保留键盘 WASD / `__test` 钩子供调试与 E2E 使用。
- 桌面：WASD/方向键 + Space/Enter，Esc = 暂停预留（仅调试路径，非玩家玩法）。
- 可交互判定：站点中心 1.15m 内 + 面向加权，最近者高亮
  (emissive 脉冲 + 世界空间图标)。

## 7. 手感与反馈

- 取/放：0.12s 手上物品弹起缩放；切：台面上的串跳切 + 进度环；
- 烤熟：串变金黄 + "叮"+ 站点上方飘烟变金；烤焦：变黑 + 灰烟。
- 收款：桌面飘 `+¥xx` 上浮文字 0.8s，HUD 营业额滚动。
- 愤怒离店：顾客头顶红怒符号 0.6s，路径回门。
- 全部反馈走 `game/flow.ts` 事件 → `ui/hud.ts` + 世界特效，数值只在 `config.ts`。
