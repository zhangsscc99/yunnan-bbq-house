### 我能做的（Capability）
- **③ 切配稳定 3 下切完**：双端标签依次是 `切配 0/3 → 切配 1/3 → 切配 2/3 → 取回切好的串`，第 3 次点击后 `chop.chopLeft = 0`、`held = chopped`，拿起后 `carrying.stage = chopped`。`port-02-chop-mid.png` / `land-02-chop-mid.png` 的金色进度条大约填到 1/3，和 `1/3` 文案一致。
- **④ 烤制时间轴与规格吻合**：上炉后 `grillT` 从 0 开始递增，**6.0–6.1s 时 `stage` 由 `chopped` 变 `cooked`**（config `grillTime: 6`），继续放超过 `12s` 变 `waste`。气泡同步切换成 `已熟 ✓`（`port-03`/`land-03`）和 `焦了 ✕`（`port-05`/`land-05`，红色进度条加红字）。
- **⑤ 装盘→上菜→收款→订单卡全链路通**：`cooked → plate` 后 `carrying.stage = plated`。走到客桌时竖屏标签是 `送去客桌`，横屏是 `上菜 烤五花肉拼盘`。交付后 `money 0 → 60`（¥48 + ¥12 小费）、`served 1`、`waste 0`；订单卡从 `烤五花肉拼盘 ¥48 · 等待` 变成 `烤五花肉拼盘 ¥48 · 用餐中`，顾客头顶同步出现「用餐中」气泡，桌上出现白盘（`port-04`/`land-04`）。
- **⑨ 连点防抖可靠**：12 次 / 1 秒的连点只产生 1 次取物，`waste` 计数保持 0（要走到垃圾桶才计），状态和控制台都干净。
- **⑩ 稳定性**：双端 `pageerror + console.error = 0`。

### 我看不懂的（Clarity）
1. **竖屏「去垃圾桶」，但垃圾桶在哪？** `port-06-spam.png` 里厨师站在烤炉前，手上是焦串，按钮写 `去垃圾桶`，画面左缘只露半个料箱，垃圾桶和另外两个料箱都在画外，也没有任何边缘箭头。横屏 `land-06-spam.png` 至少有个金色下箭头，但箭头落在左侧装饰架上，下方的垃圾桶被摇杆盖住。
2. **烤熟和烤焦只在气泡里看得出来**：`land-03-grill-cooked.png` 和 `land-05-grill-burn.png` 对比，烤炉上那根串的大小、颜色看不出差别，没有金边，也没有发黑或冒烟。拿掉气泡，玩家无法判断这根串还能不能卖（`B-064`/`B-045`/`B-027` 都没落地）。
3. **手上拿的是什么看不清**：连点后 `carrying = {pork, waste}`，但 `port-06`/`land-06` 里厨师手部看不到明显的黑串（vision 复核亦判定"看不出拿着东西"）。玩家只能靠按钮文案「去垃圾桶」反推自己拿着废料（待下轮放大截图复核）。

### P0 阻塞（不修没法玩）
1. **点按在「没有仿真步的帧」里被静默吞掉（新 → B-063；旧包 `index-ChCgL6cA.js` 与新包 `index--1CscvBg.js` 都复现）**
   - 复现（确定性）：站到料箱旁 → `__test.press(); __test.tick(0.005, 1)` → **手上仍然没有东西**；紧接着 `__test.tick(0.05, 1)`（正常一帧）→ **依然没有**，press 已永久丢失（`run-postdeploy2.json` 的 `drop: [null, null]`，05:22 新包复测）。对照：`__test.press(); __test.tick(0.02, 1)` 正常生效。
