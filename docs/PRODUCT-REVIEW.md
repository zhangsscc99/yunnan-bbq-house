### P1 明显缺陷
1. **低帧设备上游戏时钟只有墙钟的 7–10%**（B-035，**第 2 次量化**）
   - 复现：`load 12.2 / 4 核`，软渲染 1fps；开局后静置 6.03s（期间 6 帧），`timeLeft` 180 → 179.4（Δ0.60s）；横屏 6.08s / 4 帧 → Δ0.40s。按住摇杆 29.5s 墙钟 → 位移 4.18m（22 帧）。
   - 根因仍在 `src/main.ts` 的 `dt = Math.min(getDelta(), 0.1)`：1fps 时每帧只推进 0.1s，游戏时钟 = 1fps × 0.1s = **0.1×**；这就是「180 秒关卡实际跑 30 分钟而 HUD 写着 3:00」。
   - **验收：** 低帧（≤5fps）下静置 60s 墙钟，断言 `timeLeft` 减少 ≥54s（≤10% 误差）；同条件按住摇杆 2s 墙钟位移 ≥5.5m；60fps 下既有断言全绿。参考 `GAME-DESIGN §6`（3.2 m/s）、`TECH-STACK §4`（一切走 `flow.update(dt)`）。
2. **横屏左侧 18.7% 死黑且随镜头换边**（B-025，**第 5 次量到**，新增"换边"证据）
   - 复现：横屏 844×390 开局不动 → `land-02-playing.png`：左 0–160 列均值 28.0、右 160 列 93.1、连续 158 列 <55；角色移动后再截 `land-07-hud.png`：暗列降到 113 且**最右列亮度 22**。
   - 确定性：同一会话两帧黑边位置不同 → 相机横向没有夹紧在世界边界（`ART-DIRECTION §1` 的 `halfH` 公式在 844×390 给出约 20.7m 宽视野，而 `GAME-DESIGN §5` 世界只有 12×9m）。
   - **验收：** 双端 × `teleport(±5,±4.5)` 四角共 8 帧，任一帧都不存在连续 ≥24 列且亮度 <26 的区域；左右（或上下）暗区宽度差 ≤8px；连跑 3 次稳定。
3. **首屏 `blur(3px)` 把美术藏起来，结算面板也把顶部 HUD 糊掉**（B-036，**第 6 次**）
   - 复现：`getComputedStyle(.bbq-panel)` → `backdrop-filter: blur(3px)`、`background-color: rgba(12,8,5,.45)`；`port-01` / `land-01` 两次 vision 均判"场景不可辨认"；`port-14` 顶部 140px 放大后状态条文字不可读。
   - **验收：** 遮罩降到 `blur(1px)` / `rgba(12,8,5,.28)`；首屏相机取景对准「烤炉 + 炉上串 + 一位顾客」；vision 只看首屏能说出「烤炉/桌子/角色」中至少两个；结算面板顶部 140px 内状态条文字可读（或干脆在结算时隐藏 HUD）。参考 `ART-DIRECTION §1/§3`。

### P1 明显缺陷
1. **横屏 29% 纯黑虚空，且左右不对称**（B-025，**第 3 次复现**）
   - 复现：横屏 844×390 开局（不移动），截 `land-02-idle.png`；vision 量测左 160px / 右 84px 纯黑。
   - 根因不变：`ART-DIRECTION §1` 的 `halfH = clamp(max(4.8, 6.8/aspect), 4.8, 9)` 在 844×390 给出约 20.7×9.6m 视野，而 `GAME-DESIGN §5` 的世界只有 12×9m。
   - **验收：** 双端 × `teleport(±5,±4.5)` 四角共 8 帧，逐列亮度均值不存在连续 ≥24px 且 <26 的近黑列；左右黑边差 ≤8px（对称性）。
2. **「下一关」仍是假解锁**（B-012，**第 4 次复现**）
   - 复现：`money=200 → timeLeft 0` → 结算「目标达成，解锁下一关！」→ 点主按钮 → `phase=playing, money=0, timeLeft=179.6, localStorage.bbq.level='2'`，`land-05` 画面与开局**完全相同**（vision：「没有任何第2关/新关卡标识或新目标文案，和开局相比没有明显可见变化」）。
   - 代码侧：`config.LEVEL` 只有一组常量，`SAVE_KEYS.level` 全仓**无读取方**。
   - **验收：** 要么读 `bbq.level` 出真 Lv.2（目标/客流其中一项变化，并在 HUD 显示「第 2 关」）；要么文案改「再来一局挑战高分」、删按钮、不写 key。二者不可混用。
3. **竖屏开局料箱在视锥外，指引只剩一个小箭头**（backlog 中「竖屏看不到指引标记」+ B-002/B-015，**第 3 次复现**）
   - 复现：竖屏 390×844 进入游戏不移动，截 `port-03-idle.png`；`port-06` 放大后 vision 判「不存在金色环形/脉冲标记，只有一枚浅黄色向下箭头」。
   - **验收：** 竖屏开局 3s 内首屏可见料箱本体或其可辨识的定位标识（含屏幕边缘方向箭头，且箭头尺寸 ≥24px、带 2 个以上方向键特征）；`state().hint` 的屏幕投影 `onScreen===true` 或边缘箭头可见。
4. **低帧率触发时间膨胀：`dt` 钳制 0.1 让游戏时钟慢于现实**（**本轮新发现** → B-035）
   - 实测：真手指拖 44px 摇杆 **2.0s**，角色位移 **2.19m**；按 `GAME-DESIGN §6` 的 3.2 m/s 应为 6.4m，实测效率 **34%**。
   - 根因：`main.ts` 的 `dt = Math.min(clock.getDelta(), 0.1)`。5fps 时每帧只推进 0.1s → 游戏时间 0.5×；2fps 时 0.2×。**这是设计上有意的防穿模钳制，但它同时把"180 秒关卡"变成"低端机上真实 6–15 分钟"**，且玩家看到的 `时间 3:00` 倒计时与现实脱节。
   - 影响面：不是本轮这台破机器的特例——任何帧率 <10fps 的低端安卓机都会中。
   - **验收：** 在 ≤5fps 条件下（`--disable-gpu` 或 `__test` 强制低帧）跑 60s 现实时间，`timeLeft` 减少量 ≥54s（误差 ≤10%），或 HUD 在时间膨胀 >10% 时显示"设备较慢"提示。

### P1 明显缺陷
1. **横屏会露出世界外的大块纯黑虚空**（本轮新发现，最容易被读成"没做完"）
   - 复现：844×390 开局即左起 **157 列**近黑（0–157，亮度 21–24）；`__test.teleport(-5,5)` 后扩到 **258 列（≈31% 屏宽）**，边界是硬直竖切，地板砖到线即断；竖屏同位置无此现象（`port-corner` 左缘正常）。
   - 截图：`e2e/review/2026-11-20T19-44Z-r5/land-02-hud.png`（157 列）、`e2e/review/2026-11-20T19-44Z-r5/land-05-void-corner.png`（258 列，由 `__test.teleport(-5,5)` 1:1 复现）。
   - 根因（读了 `docs/ART-DIRECTION.md §1` 与 `src/config.ts`，未改码）：`halfH = clamp(max(4.8, 6.8/aspect), 4.8, 9)` 在 844×390 给出 **≈20.7×9.6m** 视野，而世界只有 **12×9m** → 横屏天生多出 ~8.7m 的空域；相机又只做 lerp 跟随、**没有夹紧到世界边界**，玩家往左走就把虚空带进画面。
   - **验收：**844×390 与 390×844 下，任意玩家位置截图**不存在连续 ≥24px 的单列亮度 <26 区域**（脚本断言：PIL 逐列均值）；或出现黑区时必须有可见背景（街道/树/围墙）而非纯色。同时 `ART-DIRECTION §1` 的 `halfH` 公式与 12×9m 世界自洽（二选一：改公式或补背景）。
2. **上错菜没有出路（逻辑死路）**（本轮新发现）
   - 复现：`spawnNow('mushroom')` 让顾客点菌子 → 做一盘**烤五花肉拼盘** → 走到该顾客桌边 → 按钮 `action='none'`、`opacity .55`、文案「这桌要的是 烤菌子」→ 长按无任何效果（`money 0 / served 0 / 菜品仍在手上`）→ 走开两步按钮变回「送去客桌」（`nextHint` 对 `plated` 恒返回「送去客桌」）→ `state().hint === null`，**全流程没有任何一处提示"去垃圾桶"**。

   - **验收：**手持 `plated` 且店内无匹配顾客时，HUD 必须出现「去垃圾桶丢弃」类指引（按钮或横幅，文本包含"丢"）；垃圾桶 `discard` 对 `plated` 生效并计 `waste`；e2e 断言：错菜状态下 `state().hint` 非 null 且指向 `bin`。
3. **烤糊只有文字，没有画面**（B-021 未修，第 2 次实证）
   - 复现：菌子烤到 `t=16.3`（`stage=waste`）截 `port-07`。vision：「有『焦了 ✕』文字，但**没有焦黑材质、没有黑痕、没有灰烟**，串本体仍偏白」；`land-02` 同判。

4. **熟度条与「已熟 ✓」语义不一致**（B-021 的另一半，第 2 轮复现）
