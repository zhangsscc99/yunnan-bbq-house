1. **横屏会露出世界外的大块纯黑虚空**（本轮新发现，最容易被读成"没做完"）

   - 根因（读了 `docs/ART-DIRECTION.md §1` 与 `src/config.ts`，未改码）：`halfH = clamp(max(4.8, 6.8/aspect), 4.8, 9)` 在 844×390 给出 **≈20.7×9.6m** 视野，而世界只有 **12×9m** → 横屏天生多出 ~8.7m 的空域；相机又只做 lerp 跟随、**没有夹紧到世界边界**，玩家往左走就把虚空带进画面。
   - **验收：**844×390 与 390×844 下，任意玩家位置截图**不存在连续 ≥24px 的单列亮度 <26 区域**（脚本断言：PIL 逐列均值）；或出现黑区时必须有可见背景（街道/树/围墙）而非纯色。同时 `ART-DIRECTION §1` 的 `halfH` 公式与 12×9m 世界自洽（二选一：改公式或补背景）。
2. **上错菜没有出路（逻辑死路）**（本轮新发现）
   - 复现：`spawnNow('mushroom')` 让顾客点菌子 → 做一盘**烤五花肉拼盘** → 走到该顾客桌边 → 按钮 `action='none'`、`opacity .55`、文案「这桌要的是 烤菌子」→ 长按无任何效果（`money 0 / served 0 / 菜品仍在手上`）→ 走开两步按钮变回「送去客桌」（`nextHint` 对 `plated` 恒返回「送去客桌」）→ `state().hint === null`，**全流程没有任何一处提示"去垃圾桶"**。

   - **验收：**手持 `plated` 且店内无匹配顾客时，HUD 必须出现「去垃圾桶丢弃」类指引（按钮或横幅，文本包含"丢"）；垃圾桶 `discard` 对 `plated` 生效并计 `waste`；e2e 断言：错菜状态下 `state().hint` 非 null 且指向 `bin`。

4. **熟度条与「已熟 ✓」语义不一致**（B-021 的另一半，第 2 轮复现）
