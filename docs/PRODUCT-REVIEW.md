### P1 明显缺陷
1. **横屏 29% 纯黑虚空，且左右不对称**（B-025，**第 3 次复现**）
   - 复现：横屏 844×390 开局（不移动），截 `land-02-idle.png`；vision 量测左 160px / 右 84px 纯黑。
   - 根因不变：`ART-DIRECTION §1` 的 `halfH = clamp(max(4.8, 6.8/aspect), 4.8, 9)` 在 844×390 给出约 20.7×9.6m 视野，而 `GAME-DESIGN §5` 的世界只有 12×9m。
   - **验收：** 双端 × `teleport(±5,±4.5)` 四角共 8 帧，逐列亮度均值不存在连续 ≥24px 且 <26 的近黑列；左右黑边差 ≤8px（对称性）。
2. **「下一关」仍是假解锁**（B-012，**第 4 次复现**）
   - 复现：`money=200 → timeLeft 0` → 结算「目标达成，解锁下一关！」→ 点主按钮 → `phase=playing, money=0, timeLeft=179.6, localStorage.bbq.level='2'`，`land-05` 画面与开局**完全相同**（vision：「没有任何第2关/新关卡标识或新目标文案，和开局相比没有明显可见变化」）。
   - 代码侧：`config.LEVEL` 只有一组常量，`SAVE_KEYS.level` 全仓**无读取方**。
   - **验收：** 要么读 `bbq.level` 出真 Lv.2（目标/客流其中一项变化，并在 HUD 显示「第 2 关」）；要么文案改「再来一局挑战高分」、删按钮、不写 key。二者不可混用。
3. **竖屏开局料箱在视锥外，指引只剩一个小箭头**（backlog 中「竖屏看不到指引标记」+ B-002/B-015，**第 3 次复现**）
   - 复现：竖屏 390×844 进入游戏不移动，截 `port-03-idle.png`；`port-06` 放大后 vision 判「不存在金色环形/脉冲标记，只有一枚浅黄色向下箭头」。
   - **验收：** 竖屏开局 3s 内首屏可见料箱本体或其可辨识的定位标识（含屏幕边缘方向箭头，且箭头尺寸 ≥24px、带 2 个以上方向键特征）；`state().hint` 的屏幕投影 `onScreen===true` 或边缘箭头可见。
4. **低帧率触发时间膨胀：`dt` 钳制 0.1 让游戏时钟慢于现实**（**本轮新发现** → B-035）
   - 实测：真手指拖 44px 摇杆 **2.0s**，角色位移 **2.19m**；按 `GAME-DESIGN §6` 的 3.2 m/s 应为 6.4m，实测效率 **34%**。
   - 根因：`main.ts` 的 `dt = Math.min(clock.getDelta(), 0.1)`。5fps 时每帧只推进 0.1s → 游戏时间 0.5×；2fps 时 0.2×。**这是设计上有意的防穿模钳制，但它同时把"180 秒关卡"变成"低端机上真实 6–15 分钟"**，且玩家看到的 `时间 3:00` 倒计时与现实脱节。
   - 影响面：不是本轮这台破机器的特例——任何帧率 <10fps 的低端安卓机都会中。
   - **验收：** 在 ≤5fps 条件下（`--disable-gpu` 或 `__test` 强制低帧）跑 60s 现实时间，`timeLeft` 减少量 ≥54s（误差 ≤10%），或 HUD 在时间膨胀 >10% 时显示"设备较慢"提示。

### P2 打磨项
1. **`favicon.ico` 404**（**本轮新发现** → B-037）：`curl /bbq/favicon.ico` → 404，本机直连控制台出现唯一一条 error。公网因 proxy 兜底而不显形，属于"只有开发者会看见的脏"。验收：`/bbq/favicon.ico` 200 + `content-type: image/x-icon`，控制台 0 条 404。

3. **动作键 caption 截断**（第 3 次复现，并入 B-008/B-015）：`.cap` 12px + 允许两行或宽度自适应（`max-width: 92px`）。
4. **顶部状态条与订单列缺稳定 id**（新 → B-038）：给「营业额/时间/评级」区块加 `#bbq-status`、订单列卡片加 `data-slot`，让 e2e 能逐项断言而不是全文匹配。
5. **首屏求"3 秒识别"已达标，但缺"3 秒想玩"**：没有角色出镜、没有炭火声、没有一张"出餐"的动效。并入 B-036 作为同一条需求的第二段。
