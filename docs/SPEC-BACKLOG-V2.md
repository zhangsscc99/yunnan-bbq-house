## 使用规则

1. 每轮只做一条：按 ID 顺序取第一个状态不是「通过」的条目。
2. 状态三档：`未核对` / `不通过` / `通过`。**只有拿到机器验收证据才能改 `通过`**，
   并在该条下追加 `- 证据：<commit> · <断言实测数字> · <截图路径>`。
3. 已达标就直接标通过，本轮不改代码（省算力）。
4. 一轮结束必须更新本文件 + 在 `docs/PRODUCT-REVIEW.md` 追加本轮发现。
5. 用户即时需求不进本清单，由调度方即时开 worktree 处理。
6. **开工前先检查**：若有 `agy --print` 进程正在跑 bbq 车道，或 `/www/yunnan-bbq-house-wt/` 下有未合入 main 的 lane 工作树 → 说明 v2 重做车道在跑，**本轮直接退出、不改任何文件**。

## 玩法铁律（任何一轮都不得违反）

- 顾客自助点单；玩家只做「取菜 / 上桌烤 / 盛盘」三件事，每次点击只做一件事
- 后台备菜是**纯计时器**，不许做成可玩小游戏
- 禁止切配台 / 装盘台 / 料箱取料 / 垃圾桶 / 手持物品跑图 / 五步出餐链
- 移动端竖屏单手是唯一验收视角（390×844），所有可点热区 ≥44px，不需要拖拽与多指

### G-02 后台自动备菜 + 出菜窗口队列
- 来源：§1 ②
- 验收断言：入座后 3.0±0.3s 该份菜出现在窗口且桌号正确；窗口容量 3，第 4 份时后台暂停（队列不增长）；每格 UI 可辨认（菜名 + 桌号）
- 状态：未核对

### G-03 取菜（手部状态）
- 来源：§1 ③
- 验收断言：点窗口托盘 → carrying 非空且 HUD 显示「手上：xx → N 号桌」；手上有菜时点其它托盘无效（队列数量不变）；角色位置移向窗口
- 状态：未核对

### G-04 上桌烤（桌面炭炉 + 火候条）
- 来源：§1 ④
- 验收断言：点该桌订单卡 → 该桌 grilling=true、火候条开始走；窗口对应那份消失；店员位置移向该桌；每桌自带烤盘（不需搬运）
- 状态：未核对

### G-05 火候判定三分支（含「焦糊只扣一次」）
- 来源：§1 ⑤ + 旧 B-156 教训
- 验收断言：完美窗内盛盘 → 满小费；夹生 → 需重铺一次（火候条重置，不扣钱）；超焦糊线 → 扣钱 + 耐心降，**且同一单不会二次扣款/二次扣耐心**
